# Aether

> A small, modern programming language built from the ground up
> as a journey into language and compiler development.

## Status

Early development.

## Goals

- Learn compiler and language design through implementation.
- Develop a clean and maintainable compiler architecture.
- Eventually make Aether self-hosting.

## Building

```
cargo build
```

## Running

```
cargo run
```
